# Pixel Resume - Gloomy Purple Edition

A retro-styled developer portfolio built with React, Vite, and Framer Motion.

## Features
- **Pixel Art Aesthetics**: 8-bit/16-bit inspired UI.
- **Gloomy Purple Theme**: Deep purples and neon glows.
- **3D Tilt Effects**: Interactive project cards using `react-parallax-tilt`.
- **Weather System**: Automatic falling rain background effect.
- **AJAX Transitions**: Smooth content loading between sections.
- **Responsive Design**: Works on mobile and desktop.

## Getting Started

1. Navigate to the project directory:
   ```bash
   cd pixel-resume
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```

## Folder Structure
- `src/components`: UI elements (Rain, Cards).
- `src/App.jsx`: Main logic and content sections.
- `src/index.css`: Global pixel styles and color variables.
